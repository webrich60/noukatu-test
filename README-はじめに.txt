やさしい脳活日和｜12ゲーム GitHub Pages テスト版 v1.6.5
=============================================================
・従来の10ゲーム＋スペシャルチャレンジ2ゲーム（新2ゲームのみ練習モードあり）
・ログイン／Firebase／GAS／AI／課金はありません。
・ニックネームや年齢、自己ベストなどは端末のブラウザに保存されます。
・「＋ ホームに追加」ボタンをヘッダーの端に追加しました。

GitHub Pagesへのアップロード
1. ZIPを解凍します。
2. 次のものをリポジトリの公開ルートに配置してください。
    index.html
    manifest.webmanifest
    sw.js
    assets/  （アイコン画像含む）
3. GitHub Pages が有効になっていることを確認してください。
4. スマホでGitHub Pagesの公開URLを開きます。

■ 以前のバージョンを更新するとき
  index.html だけでなく manifest.webmanifest / sw.js / assets/icons/ も追加してください。
  既存 assets/ の画像は変更していません。新設した icons/ 以外はそのままでも大丈夫。

■ ホーム画面へ追加
  Android Chrome：画面上部の「＋ ホームに追加」→対応時はインストール画面。
  　　　　　　　　未対応時は右上︙→「アプリをインストール」または「ホーム画面に追加」。
  iPhone Safari：画面上部の「＋ ホームに追加」→説明を表示。
  　　　　　　　Safariの共有 →「ホーム画面に追加」→「追加」。
  ※ iPhoneではアプリ内のボタンから直接追加することはできません。
  ※ インストール済みでアプリとして開いている場合、追加ボタンは非表示です。
  ※ 一部のブラウザ内蔵ビューでは追加できないため、Safari/Chromeで開いてください。

■ データとセキュリティ
  クラウドやログインは使わず、履歴は同じ端末・同じブラウザ内のみに保存されます。
  ホーム画面版とブラウザ版で記録が共有されない場合があります。
  シークレットモードやブラウザデータ消去では記録が消える場合があります。
  公開アプリの更新時はオンラインで一度ページを開いてください（静的キャッシュを更新）。

【v1.6.5】ゲーム1〜4を1ページ目、5〜8を2ページ目、9〜10と挑戦2ゲームを3ページ目に表示。「前へ」「次へ」およびページ数字・★で切り替えます。ゲーム一覧の独立スクロールは廃止。小さな画面ではホーム全体がわずかに上下します。

【v1.6.5】全12ゲーム終了後、「あなたの脳活年齢は？ ○○歳！」を表示。ゲーム内のスコア0〜100をお楽しみ用の25〜75歳に換算します。医学的診断や実際の脳年齢測定ではありません。登録年齢の表示は別途維持。新2ゲームは練習でも参考表示します。

【v1.6.5】「使い方・保存について」（折りたたみ案内）の中に、脳活年齢は成績由来のお楽しみ値で、年齢別の研究データで検証済みではない旨の注釈を追記しました。
